Diagrama de casos de uso

Actores: Invitado (no autenticado), Usuario autenticado y el subsistema Realtime como soporte técnico de los eventos de tareas. El sistema Laravel+Vue expone los casos a través de la API y la SPA.

  UC8 -.->|eventos| UC7

La línea punteada indica que la sincronización en tiempo real actualiza la vista de listado y el estado local de tareas sin sustituir el CRUD explícito del usuario.

Invitado

Puede registrarse, iniciar sesión y consultar documentación pública de la API según despliegue.

Usuario autenticado

Gestiona tareas y sesión; debe cumplir reglas de verificación de correo según configuración del backend.

Realtime

Canales públicos y privados; autenticación de broadcasting con token Sanctum.
